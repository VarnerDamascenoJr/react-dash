# React Dash Expert

Use this project-local skill for React work in `react-dash`. Paths below are
relative to this skill directory; the shared guidance stays in the repository.

Read [AGENTS.md](../../../AGENTS.md), the [project README](../../../README.md),
and the shared rules in
[React expert guidance](../../../docs/agentic/react-expert-skills.md#shared-rules).
Select the smallest applicable mode:

- [Architecture](../../../docs/agentic/react-expert-skills.md#react-dashboard-architect):
  routes, layout, page composition and state ownership.
- [Analytics UI](../../../docs/agentic/react-expert-skills.md#react-analytics-ui-specialist):
  charts, tables, feedback, exports and responsive presentation.
- [Testing](../../../docs/agentic/react-expert-skills.md#react-test-engineer):
  Vitest, Playwright and regression coverage.
- [Security boundaries](../../../docs/agentic/react-expert-skills.md#react-security-boundary-reviewer):
  auth, storage, keys, configuration and downloads.

Follow the chosen mode's references and rules. After every React frontend
implementation task, use `$react-front-test-runner` before handoff. For
required checks, including documentation-only work, follow the shared
[validation policy](../../../docs/testing.md#validation-policy).
